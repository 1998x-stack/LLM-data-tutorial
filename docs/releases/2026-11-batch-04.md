# Batch 04 · Chapters 16–20

Date: 2026-11-21

## Scope delivered

- **16 Large-scale storage:** Parquet file/row-group/column-chunk/page hierarchy, Arrow in-memory layout, Iceberg manifests and snapshots, object-store consistency, small-file and file-layout trade-offs.
- **17 Reproducible pipelines:** bitwise/semantic/statistical reproduction levels, DVC DAG and content hashes, dvc.lock, run manifests, canonical JSON digests and dataset-root fingerprints.
- **18 Data-quality evaluation:** multi-dimensional scorecard, DCLM controlled curation benchmark, Dolma corpus documentation, dataset datasheets, stratified human audit, confidence intervals and sample-size planning.
- **19 Tokenization and BPE:** adjacent-pair counting and merge ranks, character vs byte-level BPE, pre-tokenization, SentencePiece, tiktoken and a deterministic teaching implementation.
- **20 Vocabulary design:** embedding / output-head parameter cost, tied vs untied weights, logits width, multilingual token premiums, TokLens and vocabulary-size trade-offs.

## Corrections and safeguards

- Parquet row-group size and target file size are not treated as universal constants.
- Arrow in-memory layout is distinguished from Parquet persistent storage.
- Object-store strong consistency is not described as multi-object transactional commit.
- A random seed is not presented as a complete reproducibility guarantee.
- Quality is not reduced to a universal scalar; sampling assumptions and downstream recipe are explicit.
- Character-BPE sample code is explicitly marked as a teaching implementation, not a production GPT-2/tiktoken implementation.
- Vocabulary weight estimates distinguish tied and untied matrices and exclude optimizer state, activations and logits buffers.
